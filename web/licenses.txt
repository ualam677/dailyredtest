Daily Red: third-party software and content
===========================================

Pokémon FireRed (the ROM in game/)
  Built from the FireRed build of pokeemerald-expansion
  (https://github.com/rh-hideout/pokeemerald-expansion), based on the pret
  decompilations (https://github.com/pret), with Daily Red's changes.
  Pokémon and all game content are © Nintendo, Creatures Inc. and GAME FREAK
  inc. This is a free, unofficial fan project, not affiliated with or endorsed
  by them or The Pokémon Company.

mGBA libretro core (vendor/mgba_libretro.js, vendor/mgba_libretro.wasm)
  mGBA by Vicki Pfau and contributors, Mozilla Public License 2.0:
  https://github.com/mgba-emu/mgba
  Built for the browser as part of RetroArch (GNU GPL v3):
  https://github.com/libretro/RetroArch
  Build used: https://github.com/arianrhodsandlot/retroarch-emscripten-build
  (release v1.22.2). Source code for these binaries is available at the links
  above.

Graphics in the ROM
  Mt. Silver's battle background (day, evening and night): by REKKA. RED's
  battle sprite: Pokémon
  HeartGold/SoulSilver's, ripped by ChrisX698. LEAF's HGSS-style sprite.
  Mt. Silver's summit tileset and its clouds: derived from Pokémon
  HeartGold/SoulSilver.
  The HGSS-style battle interface and window frames: from Eemeliri/soulgold
  (https://github.com/Eemeliri/soulgold).
  The start menu's shelf: from a FireRed start menu patch
  (MENU_START_MI_PARCHE_REPUNTEADO, author unknown).
  The option menu: CompuMaxx's BW-style option menu, released by Shiny-Miner
  (https://github.com/Shiny-Miner/FR-OptionMenu).
  The EV/IV screen: by Acimut, Shiny Miner and Tio Terry
  (https://github.com/Shiny-Miner/Gender-based-EV-IV-Display).
  The summary screen: the BW summary by CompuMaxx, ported to FireRed by Zake
  on Acimut's template (https://github.com/Shiny-Miner/New-BW-summary-screen).
  These are recoloured red for Daily Red.
  The text font: Pokémon FireRed's, from pret/pokefirered.

Sound in the ROM
  The summit's wind: from Pokémon HeartGold/SoulSilver's Mt. Silver.
